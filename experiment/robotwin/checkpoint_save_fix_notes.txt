Checkpoint save investigation and manual restart (2026-10-15)

Observed failure
- Old run finished optimizer step 4000 at 09:59:49 local time.
- Rank 0 exited with SIGKILL (-9) at 10:00:00 while writing DCP model shards.
- Step 2000 and step 4000 use the same save implementation; there is no step4000-specific branch.
- No CUDA OOM exception, no disk-full error, cgroup oom/oom_kill counters are zero.
- The external source of SIGKILL is not established; host kernel logs are unavailable.
- Resource pressure is a hypothesis, not a confirmed root cause. These changes cannot prevent an external kill.

Confirmed implementation problems and changes
- FileSystemWriter previously used 16 threads per rank and sync_files=False.
  It now defaults to one thread per rank, with fsync enabled.
- A formal global_step directory previously existed before the save completed.
  Synchronous saves now use a hidden .incomplete staging directory, validate metadata
  and every referenced shard byte range plus rank states, fsync, then atomically rename.
  _SUCCESS.json denotes a complete distributed training-state checkpoint; HF export follows.
- Optimizer-load exceptions were swallowed and invalid checkpoints could lead to
  silently resetting training. Strict resume now rejects these failures.
- With synchronous HF export, peers could enter their next step while rank 0 merged
  model tensors. All ranks now wait for that export to finish.
- StatefulDataLoader prefetch_factor reduced 4 -> 1 (8 workers retained to allow exact
  old loader-state restoration). Global batch 768, micro batch 48, accumulation 4,
  LR 1e-4 and original optimizer/scheduler configuration are retained.
- Added per-phase checkpoint memory records and a 15-second cgroup resource monitor.

- 8-worker StatefulDataLoader prefetch4 -> prefetch1 resumes to the exact next batch.
- Legacy full step2000 passes validation; partial step4000 is rejected.
- CLI parsing, launcher CHECK_ONLY, bash syntax, Python compilation, diff whitespace checks.
- These tests validate save/resume semantics; they do not reproduce the old full-scale
