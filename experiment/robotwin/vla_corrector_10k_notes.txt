Lingbot-VLA-V2 10k + VLA-Corrector

Reference: /root/autodl-tmp/projects/vla-corrector (commit in lingbotvla/corrector/vendor/provenance.json)
Base: /root/autodl-fs/lingbotvla-robotwin-clean-sft/global_step_10000
Normalization: the base checkpoint's robotwin_clean_norm.json; no new normalization statistics.
The base policy and its visual encoder are frozen. Only the external 44,620,288-parameter MLP is trained.
This is separate from the earlier candidate-action flow refiner.

Adaptation:
- Full Qwen3-VL merged image tokens, 3 fixed cameras x 64 spatial tokens x 2560 dimensions.
- Native normalized absolute 55-dimensional Lingbot actions, padded dimensions masked to zero.
- Learn delta_z = z[t+10] - z[t] using action[t], without crossing episode boundaries.
- Reference residual MLP architecture, width2048 x4, action embedding256, dropout0.
- MSE + flattened cosine loss, AdamW lr1e-4 / weight decay1e-4, gradient clip1.
- FP32 extraction, training and inference; no compilation.
- Training: GPUs1,2,3; per-GPU batch128, global384; up to30 epochs, patience5.
- Episode-disjoint split: 45 train +5 validation per task (2250/250 episodes), seed42.
- Each500 optimizer steps saves snapshots/stepN.pt independently. latest.pt also saved each epoch.
- best.pt selected by validation MSE+cosine. Saves include optimizer, scheduler, RNG by rank, next epoch/batch, data/base/norm metadata.
- Caches use reference-style per-token int8 quantization plus fp16 scales; about252 GiB for all549787 frames.

Online integration:
- Server caches a 50-action plan but returns exactly ONE action per request, so new observations arrive after every executed action.
- Pending dynamics predictions align at exactly10 executed steps. Zero-motion residuals do not trigger a cosine detector.
- Reference robust EWMA/median/MAD threshold state machine; cooldown10; defaults recorded in monitor.py.
- Trigger discards stale plan and guides only the recovery sampling call.
- Same OGG objective as reference: attract predicted dynamics to predicted_delta - observed_delta.
- Velocity-only gradients through the frozen MLP; no base parameter gradients. eta0.1, every3 sampler steps, gradient norm capped at1.
- Online image preprocessing is matched exactly to the offline embedded-PNG pipeline.
- These are Lingbot adaptations, not a claim to reproduce published benchmark results.
